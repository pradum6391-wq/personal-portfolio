# Personal Portfolio Website

## Project Overview

This project is a personal portfolio website created using HTML5 and CSS3.

The purpose of this portfolio is to showcase my personal information, skills, profile picture, social links, and contact details in a simple, responsive, and visually appealing webpage.

The project was developed as part of my Week 2 internship task, focusing on CSS styling, layout, responsiveness, and interactive elements.

---

## Features

- Personal introduction and hero section
- About Me section
- Skills section
- Contact form
- GitHub and LinkedIn links
- Responsive navigation bar
- Responsive design for mobile and tablet devices
- Custom Google Font
- CSS color variables
- Hover effects
- Button animations
- Image hover effect
- Smooth scrolling
- CSS Flexbox
- CSS Grid

- Responsive media queries

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. The portfolio website will be displayed in the browser.

---

## Responsive Design

The website is designed to work on different screen sizes including desktop, tablet, and mobile devices.

CSS media queries are used to adjust:

- Navigation layout
- Hero section
- Font sizes
- Image size
- About section
- Skills layout
- Contact form
- Social links

The main responsive breakpoints used in the project are:

- `768px`
- `620px`
- `400px`

---

## Navigation

The navigation bar contains links to the main sections of the website:

- Home
- About
- Skills
- Contact

Internal navigation links are used to move between different sections of the page.

Example:

```html
<a href="#about">About</a>
```

## Contact Form

The contact section contains a simple form with:

- Name field
- Email field
- Message field
- Submit button

HTML form validation is used through required input fields and the email input type.
